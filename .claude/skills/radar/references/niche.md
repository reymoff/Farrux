# Поиск по нише и массовый режим

## Поиск конкурентов по нише

Владелец называет нишу и, если хочет, фильтры: гео, язык, размер аккаунта, пол и возраст. Ничего не уточнять, если ниша понятна. Не заданные фильтры не применять.

1. **Собрать кандидатов** (20-40 ников), из нескольких источников:
   - `WebSearch`: "топ <ниша> Instagram <город или страна>", "<ниша> блогер <язык>", рейтинги и подборки. Страницы с подборками прочитать агентом web-fetch и вытащить ники.
   - Аккаунты, на которые ссылаются уже найденные (отметки и упоминания в подписях из ленты).
   - `vidiq_instagram_account_discovery` и `vidiq_instagram_tiktok_outlier_search`: умеют фильтр по культуре, региону и демографии аудитории. Стоят кредиты, перед вызовом проверить `vidiq_balance` и сказать владельцу цену.
   - YouTube: `vidiq_channel_search` или `scan` по найденным каналам.
2. **Проверить каждого** через `ig_radar {username, limit: 25}` и `ingest`. Кто не открылся (личный или закрытый аккаунт), пометить и пропустить.
3. **Проставить метки** по фактам из био, подписей и кадров: `radar.py tag <ник> --niche ... --geo ... --lang ... --gender ... --age ... --kind эксперт|бренд|блогер|агентство --note "почему в списке"`.
4. **Отфильтровать и ранжировать.** По умолчанию: активен последние 30 дней, от 3 публикаций в месяц, сортировка по медиане просмотров и числу выбросов, а не по подписчикам.
5. **Отдать** таблицу топ-10 с причиной по каждому и `radar.py dash` (в дашборде фильтры по нише, гео, языку, полу, возрасту, размеру). Дальше по команде владельца полный аудит выбранных.

Что значат фильтры, честно:
- **Гео и язык**: определяются надёжно, по био, телефону, языку подписей и речи.
- **Размер, активность, ER, медиана просмотров**: точные цифры из API.
- **Пол и возраст автора**: оценка по имени, био и кадрам. Писать "оценка".
- **Пол и возраст аудитории**: Meta отдаёт их только владельцу аккаунта. Для чужих это оценка по теме и комментариям либо расчёт vidIQ. Точных цифр нет ни у кого.

## Массовый режим

Владелец может прислать сразу много: список ников или ссылок (в столбик, через запятую, как угодно), несколько ниш, либо нишу и число ("20 аккаунтов по стоматологии в Ташкенте"). Не переспрашивать, разобрать список и работать.

- **Список аккаунтов.** По каждому: `ig_radar {username, limit: 50, pages: 2}` и `ingest`. Вызовы слать пачками параллельно. Кто не открылся, записать в отдельный список "не удалось" с причиной.
- **Ниша и число N.** Собрать примерно 2N кандидатов, проверить, отфильтровать, оставить N лучших.
- **Несколько ниш.** Каждую отдельно, метка `--niche` у каждого аккаунта своя, в конце сравнение ниш между собой.

Глубина по умолчанию, чтобы не утонуть:

| Аккаунтов | Что делать по каждому |
|---|---|
| 1-3 | полный аудит, до 7 залетевших роликов смотреть и слушать |
| 4-10 | шапка, цифры, топ-3 выброса смотреть и слушать |
| 11-30 | шапка и цифры по всем; смотреть только топ-10 выбросов по всей выборке |
| больше 30 | цифры по всем, просмотр топ-10; сказать владельцу, что глубже пойдём по выбранным |

Если есть инструмент Agent, раздавать аккаунты подагентам пачками по 3-5: каждый получает ники, путь к `radar.py`, общий `RADAR_HOME` и возвращает короткий вердикт. Просмотр роликов не параллелить больше чем в 3 потока.

Итог массового разбора всегда в таком порядке: сводная таблица аккаунтов, топ залетевших по всей выборке, общие паттерны ниши (минимум два примера на каждый), кто сильнее всех и почему, свободные места в нише, что забрать владельцу. Потом файлы.
