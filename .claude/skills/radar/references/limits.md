# Где работает и что недоступно

## Где это работает

Основной режим: облако, окружение `radar-online` (сеть открыта). Компьютер владельца не нужен. Проверено из облака:

| Задача | Как | Ограничение площадки |
|---|---|---|
| YouTube: ролик | `watch`: раскадровка площадки (320x180, кадр раз в 2 сек, см. `frames.txt`) + субтитры + цифры | сам видеофайл облаку не отдаётся (проверка на бота), обходить её нельзя |
| YouTube: канал | `scan`: один лёгкий запрос, просмотры и длительность | `--full` быстро упирается в проверку на бота |
| Instagram: лента и рилсы | официальный API, см. ниже: цифры, видео, кадры, звук | только бизнес- и авторские аккаунты |
| Instagram: рилс по ссылке без API | `watch <ссылка>` | анонимно отдаёт несколько роликов, потом просит вход |

## В чате claude.ai

Скилл ставится как архив в Настройки, Возможности, Скиллы. Скрипт лежит рядом с этим файлом (`scripts/radar.py`), запускать в песочнице кода: `pip install -q faster-whisper yt-dlp`, ffmpeg там есть. Лента и ссылки на видео идут через коннектор ai-targetolog (`ig_radar` или `meta_read`). Если песочница не может скачать mp4 (сеть закрыта), сказать об этом прямо и предложить два пути: владелец присылает файл ролика в чат, либо разбор через `vidiq_watch_shortform_content`.

## Личные и закрытые аккаунты

Официальный API видит только бизнес- и авторские аккаунты. Для остальных:

- **Открытый личный аккаунт.** Список рилсов: `vidiq_ig_profile_reels` (12 штук, 5 кредитов). Просмотр: `watch <ссылка на рилс>` анонимно (несколько роликов за заход), дальше `vidiq_watch_shortform_content`.
- **Любой ролик, который владелец видит сам.** Он присылает файл (скачанный или запись экрана) в чат: `watch файл.mp4`. Без лимитов, работает и для закрытых аккаунтов, на которые он подписан.
- **Закрытый аккаунт без подписки.** Недоступен и обходить это нельзя.

## Честные ограничения

- Сохранения, репосты и охваты чужих роликов Meta не отдаёт никому. Для своих и клиентских аккаунтов они есть.
- Проверку YouTube на бота и требование входа в Instagram не обходить. Пароли и сессии Instagram в облако не брать.
- Кадры это выборка. Быстрый монтаж между точками можно пропустить, тогда поднять `--frames`.
