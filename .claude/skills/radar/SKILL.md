# radar

Скрипт: `scripts/radar.py` рядом с этим файлом. База и файлы лежат в `./radar` (или `$RADAR_HOME`).

## Где это работает

Два режима, скрипт выбирает сам.

**Облако (с телефона, окружение `radar-online`).** Проверено на YouTube: метаданные ролика, субтитры, раскадровка площадки (кадр 320x180 раз в 2 секунды, файл `frames.txt` объясняет таймкоды), лента канала одним запросом (просмотры и длительность, без дат и лайков). Не работает: скачивание самого видео и звука (хосты `*.googlevideo.com`, `*.cdninstagram.com`, `*.fbcdn.net` закрыты, добавить их может только владелец в настройках окружения), лента Instagram. YouTube после пары десятков запросов подряд включает облаку проверку на бота: не гонять `scan --full` и не смотреть больше 10-15 роликов за заход.

**Домашний компьютер.** Полный режим: видео 720p, чёткие раскадровки, хук, Whisper для роликов без субтитров, Instagram с куками браузера.

Запасной путь для Instagram из облака через коннектор vidIQ (кредиты, беречь): `vidiq_ig_profile_reels` (12 рилсов аккаунта, 5 кр.), `vidiq_watch_shortform_content` (рилс или шортс, 10 кр.), `vidiq_video_watch` (длинное видео, 25 кр.). Перед тратой проверить `vidiq_balance`.

## Команды

```bash
python radar.py watch <ссылка или файл> [--frames 24] [--lang ru|uz|en|auto] [--no-audio] [--keep]
python radar.py scan  <ссылка на канал YouTube | @ник Instagram> [--limit 30] [--shorts] [--full]
python radar.py dash
```

- `watch`: качает ролик (720p), режет раскадровки `sheet_NN.jpg` (сетка 4x3, таймкод в углу кадра) и `hook_01.jpg` (первые 3 секунды, 6 кадров), пишет `transcript.txt`. Звук: сначала субтитры площадки, потом локальный faster-whisper. Видео после разбора удаляется, если нет `--keep`.
- `scan`: лента аккаунта в базу: дата, просмотры, лайки, комментарии, длительность. Считает выброс (просмотры / медиана аккаунта) и ER.
- `dash`: один файл `radar/dashboard.html` с поиском, фильтрами и сортировкой. Открывается двойным кликом, работает с телефона.

Настройки через переменные окружения:
- `RADAR_COOKIES=chrome` (или `edge`, `firefox`): брать куки из браузера. Для Instagram почти всегда нужно.
- `RADAR_WHISPER_MODEL`: `small` по умолчанию, `medium` точнее, либо путь к своей модели CTranslate2 (у владельца есть узбекская `whisper-small-uz-v1-ct2`).
- `RADAR_IG_USER=ник`: сессия instaloader для ленты Instagram (один раз выполнить `instaloader --login ник`). Только запасной аккаунт, основной могут заблокировать.

## Как разбирать ролик

1. `watch <ссылка>`.
2. Открыть Read-ом `hook_01.jpg`, потом все `sheet_*.jpg`. Прочитать `transcript.txt`. Без этого шага ролик не просмотрен, по одному транскрипту выводов о картинке не делать.
3. Для длинных видео: `--frames 48` или больше (шаг кадров печатается в выводе). Нужен конкретный момент: `ffmpeg -ss 00:01:20 -i video.mp4 -frames:v 1 shot.jpg` при запуске с `--keep`.
4. Отдать разбор: хук (что на экране и что сказано в первые 3 секунды), структура по таймкодам, монтаж и темп, текст на экране, призыв, почему сработало, что забрать себе.

## Как разбирать конкурента

1. `scan` по каждому аккаунту (30 последних хватает для медианы).
2. Взять 3-5 роликов с выбросом от x3 и столько же провальных, прогнать через `watch`.
3. Сравнить: чем хуки, темы и формат победителей отличаются от провалов. Паттерн называть паттерном только при двух и более примерах.
4. `dash`, отдать владельцу файл и короткую выжимку.

## Честные ограничения

- Лента Instagram без входа почти не отдаётся, со входом есть риск блокировки аккаунта. Отдельный рилс по ссылке с `RADAR_COOKIES` качается стабильнее.
- Сторис, закрытые аккаунты, статистика чужих охватов и сохранений недоступны никому, кроме владельца аккаунта.
- Кадры это выборка, а не каждый кадр. Быстрый монтаж между точками выборки можно пропустить, тогда поднять `--frames`.
- Парсинг нарушает правила Instagram. Собирать только публичные данные и без фанатизма по частоте.
