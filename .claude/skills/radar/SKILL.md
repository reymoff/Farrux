# radar

Скрипт: `scripts/radar.py` рядом с этим файлом. База и файлы лежат в `./radar` (или `$RADAR_HOME`).

## Где это работает

Основной режим: облако, окружение `radar-online` (сеть открыта). Компьютер владельца не нужен. Проверено из облака:

| Задача | Как | Ограничение площадки |
|---|---|---|
| YouTube: ролик | `watch`: раскадровка площадки (320x180, кадр раз в 2 сек, см. `frames.txt`) + субтитры + цифры | сам видеофайл облаку не отдаётся (проверка на бота), обходить её нельзя |
| YouTube: канал | `scan`: один лёгкий запрос, просмотры и длительность | `--full` быстро упирается в проверку на бота |
| Instagram: лента и рилсы | официальный API, см. ниже: цифры, видео, кадры, звук | только бизнес- и авторские аккаунты |
| Instagram: рилс по ссылке без API | `watch <ссылка>` | анонимно отдаёт несколько роликов, потом просит вход |

## Instagram через официальный API (основной путь)

Бесплатно, без входа в Instagram, без риска для аккаунта. Проверено: лента, цифры, кадры и расшифровка речи рилса.

**Чужой аккаунт (конкурент).** Инструмент `mcp__ai-targetolog__ig_radar`:
1. `{username, limit: 30}`: компактная лента: код, тип, дата, просмотры, лайки, комментарии, начало подписи, `has_video`. Сохранить ответ в json и выполнить `radar.py ingest файл.json`.
2. Выбрать ролики с выбросом от x3 и вызвать `{username, limit, video_for: [коды]}`: в `videos` придут прямые ссылки на mp4.
3. `radar.py watch https://www.instagram.com/reel/КОД/ --src "ССЫЛКА" --lang ru`: чёткие кадры, хук, Whisper.

Если `ig_radar` ещё не виден в сессии, то же самое даёт `meta_read`: path `17841404159420949`, fields `business_discovery.username(НИК){followers_count,media.limit(25){permalink,media_type,media_product_type,like_count,comments_count,view_count,timestamp,caption,media_url}}` (ответ большой, брать малый limit).

Ограничения площадки: только бизнес- и авторские аккаунты; около 200 запросов в час; у рилсов с чужой лицензионной музыкой видеофайла нет (`has_video: false`), тогда `watch` по ссылке или vidIQ; сохранения, репосты и охваты чужих роликов Meta не отдаёт никому.

**Свой и клиентские аккаунты.** Полная статистика через `meta_read`: path `<ig_id>/media`, fields `permalink,media_product_type,timestamp,caption,media_url,like_count,comments_count,insights.metric(reach,views,saved,shares,total_interactions)`. Список аккаунтов и их id: `me/accounts` с `fields=name,instagram_business_account{id,username}`.

## В чате claude.ai

Скилл ставится как архив в Настройки, Возможности, Скиллы. Скрипт лежит рядом с этим файлом (`scripts/radar.py`), запускать в песочнице кода: `pip install -q faster-whisper yt-dlp`, ffmpeg там есть. Лента и ссылки на видео идут через коннектор ai-targetolog (`ig_radar` или `meta_read`). Если песочница не может скачать mp4 (сеть закрыта), сказать об этом прямо и предложить два пути: владелец присылает файл ролика в чат, либо разбор через `vidiq_watch_shortform_content`.

## Команды

```bash
python radar.py watch <ссылка или файл> [--frames 24] [--lang auto|ru|uz|kaa|en|...] [--model small|medium|large-v3] [--no-audio] [--keep]
python radar.py scan  <ссылка на канал YouTube | @ник Instagram> [--limit 30] [--shorts] [--full]
python radar.py ingest <json из Graph API>
python radar.py pics  <имя> [ссылки...] [--file ссылки.json]
python radar.py tag   <ник> [--niche --geo --lang --gender --age --kind --note]
python radar.py export [--format xlsx,csv,pdf,md,json|all] [--accounts ...] [--report файл.md] [--name имя]
python radar.py dash
```

- `watch`: качает ролик (720p), режет раскадровки `sheet_NN.jpg` (сетка 4x3, таймкод в углу кадра) и `hook_01.jpg` (первые 3 секунды, 6 кадров), пишет `transcript.txt`. Звук: сначала субтитры площадки, потом локальный faster-whisper. Видео после разбора удаляется, если нет `--keep`.
- `scan`: лента аккаунта в базу: дата, просмотры, лайки, комментарии, длительность. Считает выброс (просмотры / медиана аккаунта) и ER.
- `dash`: один файл `radar/dashboard.html` с поиском, фильтрами и сортировкой. Открывается двойным кликом, работает с телефона.

Настройки через переменные окружения (нужны только при запуске на своём компьютере):
- `RADAR_COOKIES=chrome` (или `edge`, `firefox`): брать куки из браузера. Для Instagram почти всегда нужно.
- `RADAR_WHISPER_MODEL`: `small` по умолчанию, `medium` точнее, либо путь к своей модели CTranslate2 (у владельца есть узбекская `whisper-small-uz-v1-ct2`).
- `RADAR_IG_USER=ник`: сессия instaloader для ленты Instagram (один раз выполнить `instaloader --login ник`). Только запасной аккаунт, основной могут заблокировать.

## Как разбирать ролик: почему залетел

1. `watch` (для Instagram с `--src`, см. выше).
2. Открыть Read-ом по порядку: `big_start_*.jpg` (крупно первые 3 секунды), `hook_01.jpg`, все `sheet_*.jpg`, `big_end_*.jpg` (финал). Прочитать `transcript.txt`. Без просмотра картинок выводов о картинке не делать.
3. Прочитать `experts.md` рядом с этим файлом и разобрать ролик экспертной панелью: подключить профильные скиллы владельца (сценарист Reels, психолог внимания, копирайтер, SMM-стратег, таргетолог, продажник, монтажёр), у каждого плюсы, минусы и оценка, в конце общий вердикт. Таблица ниже это минимум фактов, который должен быть в разборе. Только факты с таймкодами, каждое "почему" опирать на то, что видно или слышно.

| Блок | Что зафиксировать |
|---|---|
| Цифры | просмотры, лайки, комментарии, выброс к медиане аккаунта, ER, длительность |
| Первый кадр (0.0 с) | что в кадре, кто, план, движение, что цепляет глаз до звука |
| Заголовок на экране | дословный текст, где стоит, сколько держится |
| Хук (0-3 с) | дословно что сказано и что показано; тип: вопрос, провокация, обещание, конфликт, цифра, боль |
| Триггеры | какие эмоции и механики: страх упустить, статус, спор, узнавание себя, любопытство, польза. С таймкодом |
| Основная часть | структура по таймкодам, как удерживают: смена планов, темп, перебивки, петли, новый факт каждые N секунд |
| Оффер | что предлагают и в какой момент; если оффера нет, так и написать |
| Призыв к действию | дословно, голосом или текстом, на какой секунде, что просят сделать |
| Текст и субтитры | есть ли субтитры, стиль: по слову или строкой, выделение ключевых слов цветом, анимация |
| Шрифты | тип начертания (гротеск, антиква, рукописный, жирность), примерный размер в долях высоты кадра, цвет, обводка или подложка, положение относительно безопасных зон |
| Звук | речь, музыка, тишина, звуковые акценты; темп речи слов в минуту (слова из транскрипта / длительность) |
| Монтаж | число склеек, средняя длина плана, зумы, титры, перебивки |
| Почему залетел | 3-5 причин по убыванию силы, каждая со ссылкой на таймкод |
| Что забрать себе | 3 конкретных приёма под KaraPro и что не копировать |

Про шрифты честно: название семейства по картинке определяется приблизительно. Писать "похож на Montserrat ExtraBold" и 1-2 бесплатных аналога, не утверждать точное имя.

4. Длинное видео: `--frames 48` и больше. Конкретный момент: запуск с `--keep`, затем `ffmpeg -ss 00:01:20 -i video.mp4 -frames:v 1 shot.jpg`.

## Что делать, когда владелец прислал ссылку

Ничего не уточнять, сразу работать. Тип ссылки определяет режим:

- **Ссылка на рилс или пост** (`/reel/`, `/p/`): разбор одного ролика по схеме выше. Ник аккаунта взять из ленты, чтобы посчитать выброс к медиане.
- **Ссылка на профиль или ник**: полный аудит аккаунта, ниже.
- **Название ниши без ссылки**: поиск конкурентов по нише, ниже.
- **Несколько ссылок, ников или ниш сразу**: массовый режим, ниже.
- **YouTube**: ролик через `watch`, канал через `scan`.

## Поиск конкурентов по нише

Владелец называет нишу и, если хочет, фильтры: гео, язык, размер аккаунта, пол и возраст. Ничего не уточнять, если ниша понятна. Не заданные фильтры не применять.

1. **Собрать кандидатов** (20-40 ников), из нескольких источников:
   - `WebSearch`: "топ <ниша> Instagram <город или страна>", "<ниша> блогер <язык>", рейтинги и подборки. Страницы с подборками прочитать агентом web-fetch и вытащить ники.
   - Аккаунты, на которые ссылаются уже найденные (отметки и упоминания в подписях из ленты).
   - `vidiq_instagram_account_discovery` и `vidiq_instagram_tiktok_outlier_search`: умеют фильтр по культуре, региону и демографии аудитории. Стоят кредиты, перед вызовом проверить `vidiq_balance` и сказать владельцу цену.
   - YouTube: `vidiq_channel_search` или `scan` по найденным каналам.
2. **Проверить каждого** через `ig_radar {username, limit: 25}` и `ingest`. Кто не открылся (личный или закрытый аккаунт), пометить и пропустить.
3. **Проставить метки** по фактам из био, подписей и кадров: `radar.py tag <ник> --niche ... --geo ... --lang ... --gender ... --age ... --kind эксперт|бренд|блогер|агентство --note "почему в списке"`.
4. **Отфильтровать и ранжировать.** По умолчанию: активен последние 30 дней, от 3 публикаций в месяц, сортировка по медиане просмотров и числу выбросов, а не по подписчикам.
5. **Отдать** таблицу топ-10 с причиной по каждому и `radar.py dash` (в дашборде фильтры по нише, гео, языку, полу, возрасту, размеру). Дальше по команде владельца полный аудит выбранных.

Что значат фильтры, честно:
- **Гео и язык**: определяются надёжно, по био, телефону, языку подписей и речи.
- **Размер, активность, ER, медиана просмотров**: точные цифры из API.
- **Пол и возраст автора**: оценка по имени, био и кадрам. Писать "оценка".
- **Пол и возраст аудитории**: Meta отдаёт их только владельцу аккаунта. Для чужих это оценка по теме и комментариям либо расчёт vidIQ. Точных цифр нет ни у кого.

## Языки

Отвечать владельцу всегда по-русски. Цитаты из ролика давать в оригинале и рядом перевод.

| Что | Как понимается |
|---|---|
| Подписи, био, текст на кадрах | читаются напрямую: русский, узбекский (латиница и кириллица), каракалпакский, английский, казахский, турецкий, арабский, испанский, китайский, хинди и другие крупные языки |
| Речь | Whisper, около 100 языков. `--lang auto` по умолчанию определяет язык сам; при смеси языков в одном ролике указать основной |
| Узбекская речь | `--lang uz`: берётся модель `medium`, ошибок больше, чем на русском. Имена, бренды и цифры сверять с текстом на экране |
| Каракалпакская речь | в Whisper такого языка нет. `--lang kaa` слушает как казахский, результат черновой. Смысл восстанавливать по субтитрам на кадрах и подписи. Писать владельцу, что расшифровка приблизительная |

Перевод и проверка узбекского и каракалпакского: скилл `qaraqalpaq-translator` и коннектор Tilmoch (`mcp__Tilmoch_ai__translate`, `proofread`), если подключены. Свою точную узбекскую модель можно указать через `--model путь` или `RADAR_WHISPER_MODEL`.

При поиске по нише язык аккаунта определять по подписям и речи, а не по стране: в Узбекистане аккаунты ведут на узбекском, русском и каракалпакском вперемешку. В метку `--lang` писать код: ru, uz, kaa, en, kk и так далее; для смешанных "ru+uz".

## Массовый режим

Владелец может прислать сразу много: список ников или ссылок (в столбик, через запятую, как угодно), несколько ниш, либо нишу и число ("20 аккаунтов по стоматологии в Ташкенте"). Не переспрашивать, разобрать список и работать.

- **Список аккаунтов.** По каждому: `ig_radar {username, limit: 50, pages: 2}` и `ingest`. Вызовы слать пачками параллельно. Кто не открылся, записать в отдельный список "не удалось" с причиной.
- **Ниша и число N.** Собрать примерно 2N кандидатов, проверить, отфильтровать, оставить N лучших.
- **Несколько ниш.** Каждую отдельно, метка `--niche` у каждого аккаунта своя, в конце сравнение ниш между собой.

Глубина по умолчанию, чтобы не утонуть:

| Аккаунтов | Что делать по каждому |
|---|---|
| 1-3 | полный аудит, до 7 залетевших роликов смотреть и слушать |
| 4-10 | шапка, цифры, топ-3 выброса смотреть и слушать |
| 11-30 | шапка и цифры по всем; смотреть только топ-10 выбросов по всей выборке |
| больше 30 | цифры по всем, просмотр топ-10; сказать владельцу, что глубже пойдём по выбранным |

Если есть инструмент Agent, раздавать аккаунты подагентам пачками по 3-5: каждый получает ники, путь к `radar.py`, общий `RADAR_HOME` и возвращает короткий вердикт. Просмотр роликов не параллелить больше чем в 3 потока.

Итог массового разбора всегда в таком порядке: сводная таблица аккаунтов, топ залетевших по всей выборке, общие паттерны ниши (минимум два примера на каждый), кто сильнее всех и почему, свободные места в нише, что забрать владельцу. Потом файлы.

## Выгрузка результата

`radar.py export [--format xlsx,csv,pdf,md,json|all] [--accounts ник ...] [--report разбор.md] [--name имя]`

- **xlsx**: листы "Разбор", "Аккаунты", "Залетевшие", "Все публикации", с автофильтром и закреплённой шапкой. Открывается в Excel и Google Таблицах.
- **pdf**: текст разбора и две таблицы, альбомный A4, кириллица.
- **csv**: два файла, с разделителем `;` и BOM, чтобы Excel открыл без кракозябр.
- **md**, **json**: для заметок и для других программ.
- Дашборд с фильтрами: `radar.py dash` (html).

Порядок: написать текст разбора в файл `разбор.md`, вызвать `export --report разбор.md`, отправить владельцу файлы (в Claude Code через SendUserFile). По умолчанию отдавать xlsx и pdf, остальное по просьбе. Word или презентацию делать соответствующим скиллом (`docx`, `pptx`) из того же `разбор.md`.

Чтобы разбор ролика попал в таблицу, записать его в базу: поле `notes` у публикации (через небольшой python-однострочник над `db.json`) до вызова `export`.

## Полный аудит аккаунта Instagram

1. **Собрать всё.** `ig_radar {username, limit: 50, pages: 3}`: профиль и до 150 последних публикаций. Ответ в json, затем `radar.py ingest`. (Без `ig_radar`: `meta_read` с полями `username,name,biography,website,profile_picture_url,followers_count,follows_count,media_count,media.limit(25){permalink,media_type,media_product_type,like_count,comments_count,view_count,timestamp,caption,media_url,thumbnail_url,children{media_type,media_url}}`.)
2. **Посмотреть упаковку глазами.** `radar.py pics <ник> --file ссылки.json`: аватар, обложки 12 последних публикаций (вид сетки профиля), слайды 2-3 лучших каруселей. Ссылки на картинки: `ig_radar` с `images_for: [коды]`. Открыть листы Read-ом.
3. **Посчитать.** Медиана просмотров рилсов, ER, частота публикаций в неделю, доля форматов (рилсы, карусели, фото), лучший день и час, динамика за период.
4. **Найти залетевшие.** Все рилсы с выбросом от x3 к медиане. Если их больше 7, взять топ-7. Плюс 2-3 провальных для сравнения.
5. **Посмотреть залетевшие.** `ig_radar` с `video_for: [коды]`, затем `watch --src` на каждый. Разбор экспертной панелью (`experts.md`).
6. **Сравнить.** Что общего у залетевших и чего нет у провальных: тема, хук, длительность, формат, первый кадр, шрифт, призыв.

Отчёт по аккаунту, в таком порядке:

| Блок | Что писать |
|---|---|
| Шапка профиля | аватар (что на нём, читается ли в кружке), имя и ник, био дословно и что в нём работает, ссылка, призыв, соотношение подписчиков и подписок |
| Актуальные | через API недоступны. Написать прямо. Если владелец пришлёт скриншот профиля, разобрать по нему |
| Сетка | общий визуальный стиль 12 последних обложек: цвета, шрифты, единообразие, читаемость заголовков |
| Цифры | подписчики, медиана просмотров, ER, частота, доли форматов, таблица топ-10 по выбросу |
| Рубрики и темы | о чём пишут, какие темы дают выбросы, какие проваливаются |
| Залетевшие рилсы | по каждому короткий вердикт панели: хук, триггер, причина |
| Формула аккаунта | повторяющиеся приёмы, минимум два примера на каждый |
| Карусели и фото | лучшие по лайкам и комментариям, что на первом слайде, структура |
| Слабые места | что у них плохо и где их можно обойти |
| Что забрать себе | 5 приёмов под задачу владельца и 3 готовых хука под его нишу |
| Чего не знаю | актуальные, сторис, сохранения, репосты, охваты; рилсы без видеофайла; что не успел посмотреть |

В конце `radar.py dash` и приложить файл дашборда.

Объём: аудит одного аккаунта это много запросов и просмотров. Сначала отдать шапку, цифры и топ по выбросу, потом досматривать ролики, чтобы владелец не ждал молча.

## Личные и закрытые аккаунты

Официальный API видит только бизнес- и авторские аккаунты. Для остальных:

- **Открытый личный аккаунт.** Список рилсов: `vidiq_ig_profile_reels` (12 штук, 5 кредитов). Просмотр: `watch <ссылка на рилс>` анонимно (несколько роликов за заход), дальше `vidiq_watch_shortform_content`.
- **Любой ролик, который владелец видит сам.** Он присылает файл (скачанный или запись экрана) в чат: `watch файл.mp4`. Без лимитов, работает и для закрытых аккаунтов, на которые он подписан.
- **Закрытый аккаунт без подписки.** Недоступен и обходить это нельзя.

## Честные ограничения

- Сохранения, репосты и охваты чужих роликов Meta не отдаёт никому. Для своих и клиентских аккаунтов они есть.
- Проверку YouTube на бота и требование входа в Instagram не обходить. Пароли и сессии Instagram в облако не брать.
- Кадры это выборка. Быстрый монтаж между точками можно пропустить, тогда поднять `--frames`.
