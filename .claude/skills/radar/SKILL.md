# radar

Скрипт: `scripts/radar.py` рядом с этим файлом. База и файлы лежат в `./radar` (или `$RADAR_HOME`).

## Где это работает

Основной режим: облако, окружение `radar-online` (сеть открыта). Компьютер владельца не нужен. Проверено из облака:

| Задача | Как | Ограничение площадки |
|---|---|---|
| YouTube: ролик | `watch`: раскадровка площадки (320x180, кадр раз в 2 сек, см. `frames.txt`) + субтитры + цифры | сам видеофайл облаку не отдаётся (проверка на бота), обходить её нельзя |
| YouTube: канал | `scan`: один лёгкий запрос, просмотры и длительность | `--full` быстро упирается в проверку на бота |
| Instagram: лента аккаунта | Graph API, см. ниже | только бизнес- и авторские аккаунты; около 200 запросов в час |
| Instagram: рилс | `watch <ссылка>`: видео, чёткие кадры, Whisper | анонимно отдаёт несколько роликов, потом просит вход. Тогда `vidiq_watch_shortform_content` (10 кредитов) |

## Лента Instagram через официальный API

Бесплатно, без риска для аккаунта. Идёт через коннектор владельца `mcp__ai-targetolog__meta_read`:

- `path`: `17841404159420949` (Instagram-аккаунт владельца farrux_reymoff, от его имени идёт запрос)
- `params.fields`: `business_discovery.username(НИК){username,followers_count,media_count,media.limit(30){id,permalink,media_type,media_product_type,like_count,comments_count,view_count,timestamp,caption,media_url,thumbnail_url}}`
- Следующая страница: `media.limit(30).after(КУРСОР)`.

Ответ сохранить в json-файл и выполнить `radar.py ingest файл.json`. В ответе есть просмотры рилсов, лайки, комментарии, подписи и даты. Ошибка про отсутствие аккаунта значит, что он личный, а не бизнес: тогда только `vidiq_ig_profile_reels`.

Дальше: 3-5 роликов с выбросом от x3 прогнать через `watch`.

## Команды

```bash
python radar.py watch <ссылка или файл> [--frames 24] [--lang ru|uz|en|auto] [--no-audio] [--keep]
python radar.py scan  <ссылка на канал YouTube | @ник Instagram> [--limit 30] [--shorts] [--full]
python radar.py ingest <json из Graph API>
python radar.py dash
```

- `watch`: качает ролик (720p), режет раскадровки `sheet_NN.jpg` (сетка 4x3, таймкод в углу кадра) и `hook_01.jpg` (первые 3 секунды, 6 кадров), пишет `transcript.txt`. Звук: сначала субтитры площадки, потом локальный faster-whisper. Видео после разбора удаляется, если нет `--keep`.
- `scan`: лента аккаунта в базу: дата, просмотры, лайки, комментарии, длительность. Считает выброс (просмотры / медиана аккаунта) и ER.
- `dash`: один файл `radar/dashboard.html` с поиском, фильтрами и сортировкой. Открывается двойным кликом, работает с телефона.

Настройки через переменные окружения (нужны только при запуске на своём компьютере):
- `RADAR_COOKIES=chrome` (или `edge`, `firefox`): брать куки из браузера. Для Instagram почти всегда нужно.
- `RADAR_WHISPER_MODEL`: `small` по умолчанию, `medium` точнее, либо путь к своей модели CTranslate2 (у владельца есть узбекская `whisper-small-uz-v1-ct2`).
- `RADAR_IG_USER=ник`: сессия instaloader для ленты Instagram (один раз выполнить `instaloader --login ник`). Только запасной аккаунт, основной могут заблокировать.

## Как разбирать ролик

1. `watch <ссылка>`.
2. Открыть Read-ом `hook_01.jpg`, потом все `sheet_*.jpg`. Прочитать `transcript.txt`. Без этого шага ролик не просмотрен, по одному транскрипту выводов о картинке не делать.
3. Для длинных видео: `--frames 48` или больше (шаг кадров печатается в выводе). Нужен конкретный момент: `ffmpeg -ss 00:01:20 -i video.mp4 -frames:v 1 shot.jpg` при запуске с `--keep`.
4. Отдать разбор: хук (что на экране и что сказано в первые 3 секунды), структура по таймкодам, монтаж и темп, текст на экране, призыв, почему сработало, что забрать себе.

## Как разбирать конкурента

1. `scan` по каждому аккаунту (30 последних хватает для медианы).
2. Взять 3-5 роликов с выбросом от x3 и столько же провальных, прогнать через `watch`.
3. Сравнить: чем хуки, темы и формат победителей отличаются от провалов. Паттерн называть паттерном только при двух и более примерах.
4. `dash`, отдать владельцу файл и короткую выжимку.

## Честные ограничения

- Сторис, закрытые и личные аккаунты, чужие охваты и сохранения недоступны никому, кроме владельца аккаунта.
- Проверку YouTube на бота и требование входа в Instagram не обходить: брать то, что площадка отдаёт сама, остальное через официальный API или vidIQ.
- Кадры это выборка. Быстрый монтаж между точками можно пропустить, тогда поднять `--frames`.
