# scout

Цель: не писать с нуля то, что уже есть, и не отправлять владельца что-то ставить руками.

## Порядок поиска

Идти сверху вниз, остановиться на первом рабочем варианте.

1. **Уже подключено.** Посмотреть список скиллов и отложенных инструментов сессии, `ToolSearch` по ключевым словам задачи. У владельца подключено много коннекторов (vidIQ, Meta Ads, ai-targetolog, Supabase, Vercel, Canva и другие): чаще всего ответ уже здесь.
2. **Каталоги Claude.** `SearchSkills`, `SearchPlugins`, `SearchMcpRegistry`, `SuggestConnectors` (схемы грузить через `ToolSearch`).
3. **Открытый каталог skills.sh.** `npx -y skills@latest find "<запрос по-английски>"`. Пробовать 2-3 формулировки: короткую, по названию сервиса, по действию.
4. **GitHub.** `WebSearch` с запросом вида `github claude skill <задача>` или `MCP server <сервис> open source`.
5. **Официальный API сервиса.** Если у владельца уже есть доступ через его коннектор, это надёжнее любого парсера. Пример: лента чужого Instagram берётся через Graph API `business_discovery` в `mcp__ai-targetolog__meta_read`.

## Отбор

- Только бесплатное: без подписки, без кредитов, без обязательного платного ключа. Платное называть владельцу отдельно и не ставить.
- Смотреть дату последнего коммита и число звёзд. Заброшенное больше года брать только если альтернатив нет.
- Цифры брать с первоисточника, а не с каталогов-агрегаторов (они расходятся в разы). Порядок: `gh api repos/<owner>/<repo> --jq '[.stargazers_count,.forks_count,.pushed_at,.license.spdx_id]'`; если API закрыт (облачная сессия пускает его только к подключённым репо), открыть `WebFetch` на `https://github.com/<owner>/<repo>` и спросить звёзды, форки, issues, лицензию. Страница округляет до сотен (8.4k), этого хватает. Не удалось ни так, ни так: написать, что цифра не проверена.
- Перед установкой прочитать `SKILL.md` и скрипты целиком. Не ставить то, что просит пароли, шлёт данные на сторонний сервер или качает и запускает код без показа.
- Не ставить инструменты, чья работа сводится к обходу защиты сайта от ботов или входу в чужие аккаунты.

## Установка

- Скилл: `npx -y skills@latest add <owner/repo> --skill <имя> -y` из корня репо, чтобы он лёг в `.claude/skills` и попал в git.
- Плагин: добавить в `.claude/settings.json` (`extraKnownMarketplaces`, `enabledPlugins`) и в `scripts/setup-video-kit.sh`.
- Коннектор (MCP): подключается только в настройках claude.ai, сам его не поставить. Дать владельцу одно название и одну ссылку.
- После установки закоммитить и запушить, чтобы следующая сессия получила то же самое.
- Чат Claude (телефон, веб): туда скилл попадает только через карточку `propose_skills`, владелец сохраняет её сам. В карточку влезает один текст SKILL.md, поэтому скиллу со скриптами делать лаунчер: первым шагом он забирает репо на проверенном коммите и дальше ведёт по оригинальным инструкциям.
- Везде на компьютере: всё из `.claude/skills` этого репо `scripts/setup-video-kit.sh` линкует в `~/.claude/skills`, так что новый скилл после пуша виден в любой папке.

## После установки

Сразу выполнить исходную задачу найденным инструментом. В ответе одной строкой: что нашёл, откуда, почему выбрал. Если ничего годного нет, сказать прямо и предложить написать свой скилл.
