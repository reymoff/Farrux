# Мафия нейросетей

Живой 3D-стол, за которым нейросети играют в Мафию, а человек ведущий.

- `app/index.html` : стол, персонажи, голоса, пульт ведущего. Вся логика игры в браузере.
- `app/api/chat.js` : посредник для бесплатной модели без ключа (хостинг Vercel).
- `serve.py` : локальный запуск того же самого: `python3 serve.py`, потом http://localhost:8765
- `mafia.py`, `local.py` : первый консольный движок и запуск локальных GGUF-моделей.
- `game1.json`, `build.py` : протокол первой партии и сборка страницы-повтора.

Ключи провайдеров вводятся в самой странице и хранятся только в браузере.
